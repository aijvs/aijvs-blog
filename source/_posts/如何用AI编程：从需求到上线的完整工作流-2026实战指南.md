## 一、AI 编程三级工作流：不是所有项目都值得做

很多人一上来就想做个"AI 小红书运营助手""智能客服系统"——然后做了一半发现太复杂，放弃。

2026 年的最佳实践是**按复杂度选工作流**：

| 场景 | 你的情况 | 选哪个 |
|---|---|---|
| **写脚本** | 重复的数据处理、格式转换、单文件任务 | 第一级：Python 脚本 |
| **搭工具** | 有界面、多步骤、需要长期用 | 第二级：前端工具（HTML 单文件） |
| **做产品** | 需要数据库、多用户、长期维护 | 第三级：完整项目 |

> 💡 **核心判断标准**：这件事你愿意花多少钱和时间？
> - 10 分钟搞定 → 直接写脚本
> - 1-2 小时做个自用工具 → 搭前端
> - 想长期用 / 分享给别人 → 认真做产品

**本文做示例的是第二级：搭一个 AI 个人日志工具**（实用 + 不复杂 + 能展示完整工作流）。

## 二、提示词模板库（直接复制）

以下模板经过大量实测，直接替换方括号内容即可用。

### 模板 1：代码生成器（最常用）

```
你是一个资深[语言]工程师。请为以下功能写完整代码：

功能：[具体描述，比如"批量重命名文件夹中的图片文件"]

要求：
- 使用 [指定库或框架]
- 添加中文注释
- 处理异常情况（文件不存在、权限错误等）
- 代码可以直接运行

输出：完整可运行的代码块。
```

### 模板 2：技术选型顾问

```
我要开发一个[项目类型，比如"个人博客"或"批量处理Excel表格的工具"]，
主要功能：[列出 3-5 个核心功能]

请对比 3 种技术方案的优缺点，推荐最适合新手的方案，
并说明为什么这个方案最适合我。
```

### 模板 3：报错急救员

```
我的[语言]代码报错：

[粘贴完整错误信息]

[粘贴出错代码]

请按以下格式回答：
1. 错误原因（用大白话解释）
2. 最简单的修复方法（直接给修改后的代码）
3. 如何避免同类错误
```

### 模板 4：功能拆解师

```
我有一个想法：[描述你的需求]

请把这个想法拆解成 5-7 个具体可执行的子任务，
每个子任务说明：
- 具体要做什么
- 关键技术点
- 预计实现难度（1-3级，3是最难）
- 是否有现成轮子可用
```

### 模板 5：架构设计（进阶）

```
我要做一个[项目类型]，[具体描述核心功能]。

项目要求：
- 目标用户：[谁会用]
- 技术偏好：[prefer Flask/Django/React/Vue/纯前端等，或"没有偏好，你来选"]
- 部署环境：[本地/服务器/免费托管等]

请给出：
1. 推荐的目录结构
2. 每个文件的核心职责
3. 数据如何存储
4. 可能的扩展方向
```

## 三、实战：从零搭一个 AI 个人日志系统

目标：做一个单文件 HTML 日志工具，支持以下功能：

- 每天写日志（带日期和标签）
- AI 自动给日志分类打标签
- 按关键词搜索历史日志
- 一键导出为 Markdown 文件

**这个工具 90% 的代码是 AI 写的，我只做了需求描述和人工 review。**

### Step 1：用模板 4 拆解任务

把下面这段话直接发给 TRAE 或通义灵码（选一个你装了的中文 AI 编程工具）：

> "我想要一个单文件 HTML 工具，功能：写每日日志（日期+内容+标签），有搜索框可以搜索历史日志，有导出按钮把日志导出为 Markdown 文件。请拆解成具体的开发任务。"

AI 会返回类似这样的任务清单：

```
1. 搭建 HTML 基础结构（输入区 + 历史列表 + 搜索区）
2. 用 LocalStorage 保存日志数据（避免后端）
3. 实现关键词搜索功能
4. 实现 Markdown 导出功能
5. 样式美化（Tailwind CDN）
```

### Step 2：用模板 1 生成核心代码

把下面这段发给 AI（直接复制粘贴，把括号里的需求改一下就行）：

> "请用纯 HTML + JavaScript 写一个单文件应用：
>
> - 左侧：写日志区（日期自动填充，内容输入框，标签输入框，提交按钮）
> - 右侧：历史日志列表（每条显示日期、标签、内容摘要）
> - 顶部：搜索框（输入关键词实时过滤日志）
> - 底部：导出按钮（导出所有日志为 Markdown 文件）
> - 用 Tailwind CDN 做样式
> - 数据存在 LocalStorage 里，不需要后端
> - 代码直接可以打开浏览器运行"

**AI 会返回完整代码，保存为 `index.html` 双击就能用。**

### Step 3：加上 AI 分类功能（可选增强）

发给 AI：

> "在我的日志工具里加一个「AI 分类」按钮。点击后：
> 1. 把日志内容发给免费的 AI API（用硅基流动或 DeepSeek 免费接口）
> 2. AI 返回 2-3 个标签建议
> 3. 自动填入标签框
>
> 请补充相关代码，并告诉我需要在 HTML 里加什么。"

这个功能稍微复杂，但 AI 能帮你把代码模块化——"分类逻辑"和"UI 逻辑"分开，代码依然清晰。

## 四、代码质量检查清单（人工必做）

AI 写的代码没有 bug 是幻觉。以下是人工 review 的最低检查项：

- [ ] **功能测试**：每个按钮、每个输入框都点一遍
- [ ] **边界测试**：空输入、超长文本、带特殊字符（`#%、*`）的内容都能正常处理
- [ ] **数据安全**：日志存在 LocalStorage 里不会上传（除非你加了云同步功能）
- [ ] **依赖检查**：AI 可能引用了不存在的 CDN 链接或库版本

> 💡 如果你不懂代码，**找一个懂的朋友帮你 review 5 分钟**。这一步值千金。
