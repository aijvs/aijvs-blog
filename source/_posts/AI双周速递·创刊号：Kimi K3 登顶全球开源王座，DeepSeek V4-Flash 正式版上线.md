## 一、头条：Kimi K3 —— 全球最大开源模型诞生

**7 月 16 日**，月之暗面（Moonshot AI）发布旗舰大模型 **Kimi K3**；**7 月 27 日**，完整模型权重正式开源。

### 核心数据（置信度：高，多个独立来源交叉验证）

| 指标 | 数值 |
|---|---|
| 总参数 | **2.8 万亿**（全球最大开源模型） |
| 激活参数 | 约 1040 亿（MoE，896 专家每 Token 激活 16 个） |
| 上下文窗口 | **100 万 Token**（单次可处理约 75 万单词） |
| 能力 | 原生视觉理解，文本/图像/视频多模态 |
| 编程榜单 | Frontend Code Arena **1679 分**登顶，超越 Claude Fable 5（1631）和 GPT-5.6 |
| 开源时间 | 2026-07-27 深夜，完整权重 + 技术报告 |

### 为什么重要？

**这是中国大模型第一次在"开源 + 规模"两个维度同时登顶。**

- 2.8 万亿参数 = 全球首个开源 3 万亿级（约 2.8T）模型
- 稀疏 MoE 架构 + 自研 KDA 注意力，让"大而快"成为可能：总参数 2.8T，但每次推理只激活约 1040 亿参数，算力成本没有等比膨胀
- 发布后，美股 AI 板块 72 小时内蒸发约 4700 亿美元——市场在重新审视"闭源模型的天价资本开支是否合理"

### 对普通学习者意味着什么？

**你可以用更低的成本，跑更强的模型。** 开源意味着权重公开、可私有化部署、可研究原理——这正是学习 AI 最好的土壤。我们后续会推出"Kimi K3 架构解读"系列，从 MoE 混合专家讲起，让你看懂 896 个专家是怎么协作的。

## 二、DeepSeek V4-Flash 正式版 API 上线

**7 月 31 日**，DeepSeek 通过 API 文档发布日志，宣布 **DeepSeek-V4-Flash 正式版（V4-Flash-0731）** 上线公测。

### 核心要点（置信度：高）

| 维度 | 详情 |
|---|---|
| 版本 | V4-Flash-0731，仅重新后训练，架构与 4 月预览版一致 |
| 模型名 | 开发者继续用 `deepseek-v4-flash` 调用，后台自动切换 |
| 重点升级 | **Agent 能力大幅增强**，基准测试远超 V4-Pro-Preview |
| 原生支持 | Responses API 格式，针对性适配 Codex |
| 参数规模 | 约 130 亿激活参数 |
| 性价比 | 约 98% 缓存命中率，打造极致性价比 |

### 为什么值得关注？

这是继 4 月 24 日 V4 预览版发布以来的**首次重大升级**。特别值得注意的是：

- 名字带 "Flash" 但定位不低——130 亿激活参数做到了"以下克上"，在 WebDev 基准拿到 1577 分（对比 Kimi K3 的 1679）
- **Agent 能力是本次升级核心**——AI 从"回答问题"走向"替你干活"，这是 2026 年最大的技术主线
- V4-Pro 正式版"将尽快发布"，预计 8 月初——下一期速递大概率有它

### 对开发者意味着什么？

如果你在做 AI 应用，**优先试试 V4-Flash**。缓存命中率 98% 意味着同样的功能、更低的延迟和成本——对个人开发者尤其友好。

## 三、WAIC 2026：具身智能成为绝对主角

**7 月 17-20 日**，世界人工智能大会（WAIC 2026）在上海举行。

### 重点观察（置信度：中高）

- **具身智能爆发**：全国首个具身智能发展局揭牌；魔法原子发布通用具身大模型 Magic-VLA K02，打造"物理 AI 平台大脑"
- **长安天枢智能机器人**：布局具身智能，首批搭载 DingOS，让 AI 融入 0.65 升空间
- **应用竞争取代模型竞赛**：多篇行业观察指出，大会展示的重心从"谁家模型更强"转向"谁家应用和生态更完整"
- **通义千问进入特斯拉中国车机深度测试**——大模型上车成为趋势

### 对学习者意味着什么？

具身智能（机器人 + AI）是继大模型之后的下一个风口。它需要的能力组合很清晰：**计算机视觉（让机器看见）+ 强化学习/控制（让机器行动）+ 大模型（让机器理解）**。你现在学的 CV 基础，正是具身智能的第一块砖。
